# PRODIGY_GA_01

## Text Generation with GPT-2

### Objective

The objective of this project is to generate coherent and contextually relevant text using the GPT-2 language model.

### Tools and Technologies Used

* Python
* Google Colab
* Hugging Face Transformers
* GPT-2
* PyTorch

### Project Workflow

1. Installed the required libraries.
2. Loaded the pre-trained GPT-2 model.
3. Provided custom text prompts.
4. Generated AI-based text responses.
5. Evaluated the generated outputs.
